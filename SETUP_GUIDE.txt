백패킹 체크리스트 V2.0 — 설정 안내

1. https://console.firebase.google.com 에서 프로젝트 만들기. 요금제 Spark(무료) 유지.
2. 프로젝트 설정 > 내 앱 > 웹 앱 등록. 앱 설정 firebaseConfig 값을 firebase-config.js에 입력.
3. Authentication > Sign-in method > 이메일/비밀번호 사용 설정.
4. Firestore Database > 데이터베이스 만들기 (프로덕션 모드), Rules 탭에 firestore.rules 내용을 복사해서 Publish.
5. Authentication > Settings > Authorized domains에서 lji22276837-byte.github.io 추가 (필요하면).
6. GitHub 저장소 backpacking-checklist 최상위에 index.html, manifest.webmanifest, sw.js, icon-*.png, firebase-config.js 업로드.
7. 기존 앱에서 백업 저장하고, V2.0에서 개인 모드로 백업 불러오기. 로그인 후 '현재 체크리스트로 클라우드 보드 만들기'.
8. iPhone과 PC에서 같은 보드 주소를 사용, 같은 계정으로 로그인. 친구에게는 보기 전용 링크 전송 가능.
9. 친구 편집: 친구가 링크 접속, 가입/로그인, 화면의 UID 복사해서 보드 소유자에게 전달. 소유자가 '편집 권한 추가'에 UID 등록.

주의:
- 보기 전용 링크를 아는 사람은 내용을 볼 수 있습니다. 이름/위치 등 민감한 정보를 메모에 넣지 마세요.
- 소유자의 링크는 공유 보드 주소이며, 링크 소유만으로 수정은 불가합니다.
- 클라우드 변경은 온라인일 때만 저장됩니다. 오프라인에서 공유 보드를 편집하지 마세요.
- 동시 편집 시 마지막으로 저장된 전체 장비 목록이 이길 수 있습니다. 같은 순간 같은 보드를 편집하지 않는 것을 권장합니다.
- Firestore 데이터는 보드 한 문서에 저장됩니다. 개인/소규모 사용을 위한 초기 버전입니다.
- Spark 무료 한도 안에서만 무료이며 사용량 초과 시 제한될 수 있습니다.
- GitHub Pages 웹사이트 주소는 그대로 유지. 변경 전 반드시 JSON 백업하세요.
