백패킹 체크리스트 V1.3 — iPhone 홈 화면용 PWA

1. 이 폴더의 파일 전체를 HTTPS 정적 웹 호스팅(Netlify Drop, GitHub Pages 등)에 업로드하세요.
2. 아이폰 Safari에서 배포된 https:// 주소를 엽니다.
3. 인터넷에 연결된 상태로 페이지를 한 번 실행하고 “오프라인 사용 준비 완료” 표시를 확인합니다.
4. Safari 공유 → 홈 화면에 추가 → 추가.
5. 비행기 모드에서 홈 화면 아이콘으로 실행하여 오프라인 작동을 확인하세요.

주의:
- 아이폰 파일 앱의 HTML 미리보기에서는 JavaScript와 PWA 기능이 정상 작동하지 않을 수 있습니다.
- 홈 화면 앱의 저장 공간과 Safari의 저장 공간은 iOS 버전·설치 방식에 따라 분리될 수 있습니다. 최초 설치 후 백업 불러오기로 필요한 데이터를 가져오세요.
- 로컬 저장(localStorage)은 기기·사이트별이며 iCloud 동기화가 아닙니다. 사이트 데이터 삭제, 앱 삭제 시 데이터가 유실될 수 있으므로 백업 파일을 안전하게 보관하세요.
- 처음 온라인 접속 및 캐시 설치가 필요합니다. 인터넷 연결이 없는 상태로 첫 설치는 불가능합니다.
