백패킹 V2.8.2 기본 장비 복원 기능

1. 기존 클라우드 보드의 링크와 현재 데이터를 확인합니다.
2. 장비 관리 > 백업 저장으로 JSON 파일을 다운로드하고 파일이 실제 저장되었는지 확인합니다.
3. 기본 목록 복원 버튼을 누르고 확인합니다.
4. 최초 13개 대분류 이름/순서 및 기본 장비명/설명/우선순위가 복원됩니다.
5. 기존 기본 장비의 체크/메모/무게/수량, 직접 추가한 대분류/장비, 박지, 장비 구성은 유지됩니다.
6. 클라우드에 저장 완료를 확인하고 PC/아이폰 동일 보드에서 목록 확인합니다.
7. 되돌리고 싶을 때 백업 불러오기로 다운로드한 JSON을 가져옵니다. 가져오기는 현재 자료를 덮어쓰므로 다시 한 번 현재 상태를 백업하세요.

기본 목록 복원은 직접 추가한 항목을 제거하지 않습니다. 이것은 사용자 데이터를 보호하기 위한 설계입니다.
