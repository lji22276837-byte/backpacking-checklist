V2.5 변경 사항
1. 체크한 장비만 무게 합산, 해제하면 합계에서 제외
2. 개당 무게 입력 오른쪽에 g 표시, 수량 옆 중복 합계 삭제
3. 데스크톱 폭과 필드 간격 개선
4. 여행 선택(activeTripId)을 기존 Firestore 보드에 저장하여 같은 보드의 PC/아이폰 선택 상태 동기화

적용 순서:
- 기존 앱에서 JSON 백업 및 현재 보드 링크 보관
- Firestore 규칙 탭에서 새 firestore.rules 전체 붙여넣고 게시
- GitHub 저장소 최상위에 V2.5 파일들 업로드 후 배포 성공 확인
- 양쪽 기기에서 기존 동일 보드 주소 접속 및 새로고침

주의: 여행 선택은 같은 보드를 쓰는 친구에게도 동기화됩니다. 같은 여행을 작업할 때 유용합니다.
동시 변경은 마지막 저장이 우선할 수 있습니다.
