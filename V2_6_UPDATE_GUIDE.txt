백패킹 체크리스트 V2.6 업데이트

변경점:
1. 장비 추가 영역을 대분류 목록 위로 이동했습니다.
2. 여행별 체크리스트에서 새 장비가 사라지는 문제를 수정했습니다. 현재 여행을 포함한 기존 모든 여행 목록에 새 장비를 추가합니다.
3. 추가 후 검색/필터를 초기화하여 새 장비가 즉시 보입니다.
4. 기존 Firebase 데이터 구조, 로그인, 메모 입력 안정화 및 동기화 코드는 유지합니다.

업데이트:
- 현재 V2.5 클라우드 보드에서 JSON 백업을 먼저 저장하세요.
- GitHub 저장소 최상위에 V2.6 폴더 안의 웹 파일을 업로드하고 Commit changes 하세요.
- GitHub Actions에서 최신 Pages 배포 성공 후 V2.6을 확인하세요.
- Firestore 규칙 변경은 필요 없습니다.
- 새 여행을 만들거나 기존 여행을 선택해 장비를 추가하고 PC/아이폰 양쪽에서 보이는지 시험하세요.
- 주의: 새로 추가한 장비는 모든 기존 여행에 포함됩니다. 필요에 따라 이후 여행별 제외 기능을 구현할 수 있습니다.
