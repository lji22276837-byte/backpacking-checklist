V2.9 업데이트 안내
1. 현재 V2.8.2에서 JSON 백업 저장 및 보드 링크 기록.
2. 본 폴더의 파일들을 기존 GitHub Pages 저장소 루트에 업로드하여 동일 파일 교체.
3. 이번 릴리스는 Firestore 보안 규칙 변경이 필요하지 않습니다.
4. 장비 및 박지 데이터 스키마를 유지합니다.
5. 지도 열기: 박지 지도 링크 또는 주소 입력. 주차 위치도 별도로 기록 가능합니다.
6. 수정 이력: 장비 관리의 수정 이력 버튼. 이력은 기기 브라우저별로 저장되며 클라우드에 동기화되지 않습니다.
7. 복원 전 반드시 JSON 백업을 다운로드하십시오. 복원 후 클라우드에 저장 완료 표시 확인.
8. 주의: 공동 편집 시 동시 변경이 충돌할 수 있습니다. 실제 iPhone Safari와 Firebase 테스트는 배포 후 진행하세요.
