백패킹 체크리스트 V2.2 설치 가이드

[매우 중요] 데이터 보존
1. 기존 웹앱에서 JSON 백업을 받아 보관하세요. 클라우드 데이터는 삭제하지 않습니다.
2. Firebase Firestore > 규칙에서 이 폴더의 firestore.rules 내용으로 전체 교체 후 [게시]하세요. V2.2에서 내 보드를 자동 검색하려면 새 규칙이 필수입니다.
3. 이 폴더 안 파일들을 GitHub 저장소 backpacking-checklist 최상위에 업로드하고 Commit changes 하세요.
4. Actions 배포 성공 확인 후 Safari에서 앱을 새로고침하세요. 아이폰 홈 화면 앱을 재시작해 확인하세요.
5. 로그인 후 ?board= 링크가 없는 일반 주소에서도 내 소유 보드를 자동 조회하여 열도록 변경했습니다. 기존 공유 링크는 그대로 사용 가능합니다.

한 계정에 여러 보드가 있으면 생성일 기준 가장 최근 보드가 열립니다. 기존 보드 ID 및 메모는 바뀌지 않습니다.
친구가 소유한 공유 보드는 소유자가 전달한 링크로 접속해야 합니다.
자동 탐색은 인터넷 연결 시 작동합니다. 오프라인에서는 기존 개인 모드만 사용 가능합니다.
주의: 여러 기기/여러 사람이 같은 시점에 수정 시 마지막 저장이 이길 수 있습니다.
